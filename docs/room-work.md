# 多房间需求整理

每个房间以户型稳定 ID 保存独立访谈草稿、问卷位置、确认记录与已保存需求。房间名称用于展示，需求编号以房间前缀隔离。保存某个房间只替换它原有的条目，不改其他房间，也不改已发布快照。全屋与公共需求有独立入口。

保存房间后等待本机项目写入，再回到房间选择；底栏提供查看总清单。总清单只包含各房间已保存内容，进行中的修改保留在对应草稿，提交确认会说明这一范围。旧版单份项目作为“原有全屋需求”保留，不自动拆分或丢弃。

验证：129 项前端测试通过，TypeScript/生产构建通过。独立浏览器测试验证卫生间与客厅表达互不串写、切换及刷新恢复、保存两个同为 N001 的条目得到不同房间编号、保存后立即刷新仍保留总清单。保存/恢复测试采用明确标记的合成问卷，不表示本轮测试了新的模型行为。需求接口未改变。
