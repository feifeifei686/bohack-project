# 明码本机部署

本机入口是 **[http://127.0.0.1:5188/](http://127.0.0.1:5188/)**。刷新或重新打开页面会开始新一轮演示。

前端直接进入澄境，AI 接口作为独立服务运行。需求共创已接入 AI 拆分、动态追问和草稿确认，上传图纸可调用 AI 识别房间、门窗和家具；商家比对、修订及独立工程预览仍保留本地演示逻辑。

## 日常使用

在项目根目录双击以下文件：

本次安装也在桌面的“明码本机版”文件夹中创建了这些入口的快捷方式。

| 文件 | 作用 |
| --- | --- |
| [启动明码.command](../启动明码.command) | 准备依赖、构建并启动服务，打开网页；已经就绪时直接打开现有服务 |
| [停止明码.command](../停止明码.command) | 停止本项目管理的网页和接口服务 |
| [查看明码状态.command](../查看明码状态.command) | 查看服务是否就绪、进程和日志位置，不调用模型 |
| [更新明码.command](../更新明码.command) | 重新构建当前本地源码并重启服务；不自动拉取 GitHub 代码 |
| [开启局域网访问.command](../开启局域网访问.command) | 允许同一局域网访问网页，并显示当前访问地址 |
| [关闭局域网访问.command](../关闭局域网访问.command) | 恢复网页仅本机访问 |

服务由当前 macOS 登录会话管理，关闭启动终端后仍可访问。**重启电脑或退出登录后，再双击“启动明码.command”恢复。** 配置保存在项目的 `.local-run/`，没有安装到 `~/Library/LaunchAgents`，也不修改开机或登录启动设置。

首次准备依赖需要网络和 Node.js 24 或更新版本。构建后使用的是静态网页；修改源代码后通过“更新明码.command”刷新部署。更新期间服务可能短暂不可用。

## 服务地址

| 地址 | 用途 |
| --- | --- |
| [127.0.0.1:5188](http://127.0.0.1:5188/) | 澄境演示首页 |
| [5188/api/health](http://127.0.0.1:5188/api/health) | 通过同源入口检查 AI 服务状态 |
| [5188/api/openapi.json](http://127.0.0.1:5188/api/openapi.json) | 同源接口契约 |
| [5199/api/health](http://127.0.0.1:5199/api/health) | 直接检查后端接口状态 |

默认两个服务只监听本机回环地址。开启局域网共享后，网页 5188 监听 IPv4 网络接口，允许私有 IPv4 局域网访问；AI 服务 5199 始终只监听本机。同一局域网中的设备可通过网关直接使用 `POST /api/ai/intake` 和 `POST /api/ai/floorplan`，无需访问码；其他 API 和运行诊断请求仍返回 403。

本机通过 `127.0.0.1:5188` 的 `/api/*` 请求仍会转发到 5199；后续页面可调用同源接口，具体字段见 [AI 接口文档](api/README.md)。健康检查不会产生模型用量；真实 AI 请求会使用服务端配置的 DeepSeek 账户。

## 手机或其他电脑访问

1. 双击“开启局域网访问.command”，或打开“查看明码状态.command”读取当前局域网地址。
2. 让其他设备与这台 Mac 连接同一局域网，在浏览器输入状态窗口显示的 `http://<电脑局域网IP>:5188/`。
3. 保持 Mac 开机、未休眠且服务运行。重连网络后 IP 可能变化，请重新查看状态。

同一局域网中的设备打开网页后，可以直接上传图纸进行 AI 识别，或开始 AI 需求共创，无需填写密码或访问码。

网关继续检查私有 IPv4 来源、主机名和网页同源来源，后端保留请求限流与并发限制。DeepSeek API Key 只由服务端读取，不发送给浏览器。

开关选择保存在 `.local-run/access.json`，启动和更新会沿用该选择。地址从当前网卡动态读取，不在代码中固定。若同一 Wi-Fi 仍无法访问，访客网络或校园网络可能阻止设备间通信；需使用允许设备互访的网络。

访谈、需求、方案、上传图纸和项目记录只在当前页面的本轮演示中保留。刷新或重新打开即清空，可提前导出项目记录。局域网入口只开放需求共创和户型识别，不提供用户账户、跨设备数据同步或其他 AI 接口权限。

## 配置与日志

- 模型密钥保存在 `mingma-api/.env`，该文件仅供服务端读取，已排除 Git 跟踪。不要把密钥放进网页代码或截图。
- `.local-run/logs/` 保存网页与接口的运行日志；`.local-run/` 保存当前电脑生成的服务配置与状态，已排除 Git 跟踪。
- 修改 `.env` 或源码后，使用“更新明码.command”重新启动。接口健康状态中的 `aiConfigured` 只表示已配置密钥，不等于完成真实模型调用验证。
- 如果端口被其他程序占用，启动程序会报告冲突，不自动终止陌生进程。先检查占用者，再处理冲突。
- 搬移或重命名项目文件夹前，先停止服务；移动后从新位置重新启动。

如需留存本轮填写内容，请在刷新或关闭页面前导出项目。
