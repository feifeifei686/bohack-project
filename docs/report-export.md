# 报告导出结构

P1 映射用户的“必须满足”，P2 映射“优先偏好”。这表示需求的重要程度，不代替风险等级、施工顺序或专业判断。待确认事项按这一优先级排列，保留责任方、需求编号和影响方案方向的状态；未指定责任方时仍显示待定。

报告包含项目摘要、可点击目录、优先级与待办、分房间需求、空间背景、方案差异和原文、评估快照、选择记录与协作轨迹。当前草稿与已发布方案基准继续区分；各房间未保存的修改在首页提示。

PDF 沿用浏览器打印/另存为 PDF，通过 A4 样式提供页眉和“第 n 页 / 共 m 页”。短章节连续排版，主要部分分章；表头可重复，需求与对应证据尽量同页。

验证：130 项前端测试通过，生产构建通过。已用三房间合成资料生成 output/pdf/装修需求沟通报告-示例.pdf，并用 Poppler 渲染全部 12 页检查版面。该文件仅为排版示例，不包含真实业主资料。
