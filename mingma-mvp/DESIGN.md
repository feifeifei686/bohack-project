# 明码光学玻璃工作台

采用浅色扁平简约插画与光学玻璃材质。左侧标题和主行动定义下一步，右侧白色与冰蓝轴测户型形成视觉主体，当前房间信息悬浮在模型前。背景的低饱和光场与柔和曲面透过玻璃产生真实模糊。底部磨砂导航保留全部原有功能。

使用系统无衬线字体与中文后备，保持接近原生界面的文字节奏。首页标题42至82px流动字号，正文14至15px，辅助说明12px。图标使用统一线性SVG。状态颜色始终配有文字。

## 空间与交互

使用三维顶点正交投影的SVG绘制简约轴测户型，白墙、浅砂和冰蓝色块、有限明暗面与柔和底板阴影形成轻巧插画感。保留墙体、家具、路线、鼠标拖动、键盘旋转、缩放和俯视。示意户型与真实方案数据区分，不展示没有来源的商家路线。房间与路线选择均有文字按钮替代。

导航窄屏显示图标与短标签，宽屏显示完整名称；底部操作区预留导航空间。宽表在容器内部滚动。保留键盘焦点、主要操作44px触控目标与减少动态效果设置，不自动旋转模型。

## 实现

Tailwind CSS v4 编译工具类与主题变量。style.css定义基础、光学背景与导航；workspace-glass.css定义各操作页面；glass-model.ts绘制户型。玻璃外层使用22至30px backdrop-filter blur并提供WebKit版本，内层表格行不重复模糊。白色极细边缘、内高光与偏移柔阴影表示材质厚度，渐变只用于表面反光和环境光。无背景滤镜支持或偏好减少透明度时降级为清晰浅色表面。动效只使用短时CSS反馈。
