# 澄境 Lucid 空间工作室

Lucid 面向希望逐项把需求说清楚的业主，采用通透的白色光学玻璃与低饱和冰蓝。页面结构以工作任务为中心：顶部项目导航，首页放置项目简报，第二页使用左侧沙盘与右侧需求清单。没有底部浮动导航或传统固定侧栏。

## 组成

- 首页展示真实本机项目状态、「开始硬装规划」和协作轨迹。第二页「空间选择」提供演示沙盘和区域硬装清单。
- 共创页是左侧问题工作纸与右侧需求摘要。手机先呈现问题，摘要按顺序跟随。
- 需求清单保留草稿、优先级、版本发布与逐项编辑；工具条与记录保持同一视觉层级。
- 方案对比以同一需求编号为横轴，保留原文证据、问题反馈和旧版失效提示。
- 商家工作区使用需求说明与回应表单对照布局，提交操作条保持可见。
- 空间页是可旋转、可切图层的示意模型与信息抽屉。缺少商家空间数据时不展示样例管线。
- 我的需求统一展示清单、派生待办和项目背景；背景只填写一次并带入共创，旧维度记录以只读档案保留。
- 确认记录保存被选定的需求与方案快照，当前需求改变后明确指出历史选择状态。

## 视觉变量

| 用途 | 值 |
| --- | --- |
| 页面底色 | #eef4f9 |
| 玻璃面板 | rgba(255,255,255,0.64) |
| 主要文字 | #253b50 |
| 次级文字 | #5d7185 |
| 强调色 | #28699f |
| 主按钮 | #3b7daf |
| 分隔线 | rgba(106,137,164,0.19) |

中文使用平台无衬线字体，标题27至39px，功能正文14px，辅助说明11至12px。玻璃仅用在分离任务层次的外容器，采用真实背景模糊、细白边缘、柔和阴影；表格内部不重复加滤镜。

## 交互细节

手机首页额外提供靠前的主行动。横向项目导航在进入页面时自动定位当前标签；表格在自身容器内滚动，不撑宽页面。房间、线路和视图均有文字操作作为替代。关键操作有键盘焦点、触控目标和明确的保存状态。

## 代码与资产

Tailwind v4 工具类配合组件CSS。`src/main.ts` 保存页面模板和客户端交互；`src/style.css` 定义 Lucid 外壳、空间工作台和各任务页面的细节；`workspace-glass.css` 保留共享任务组件基础；`glass-model.ts` 提供SVG三维投影。域规则 `domain.ts` 未改变。

室内素材使用设计展厅共享的 `/assets/lucid.webp`，生成出处及提示词保存在展厅 `public/assets/manifest.json` 与 `lucid.prompt.txt`。素材只表达氛围，不表示真实商家提供的方案。
