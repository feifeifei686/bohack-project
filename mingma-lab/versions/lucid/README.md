# 明码澄境 Lucid

这一版以清楚的空间协作为中心。进入首页后，先看项目简报与下一步，再点选房间了解区域需求；顶部工作标签连接完整流程。视觉采用通透白色、冰蓝、光学磨砂与柔和窗光。

## 入口

开发服务启动后访问 `/versions/lucid/index.html`。每页右上角可返回设计展厅，手机显示返回箭头并提供无障碍名称。

## 推荐验收

1. 点击开始梳理需求，填写原始表达并完成五组基础选择题。
2. 在需求清单修改重要程度、补充自定义需求并发布版本。
3. 载入两家模拟商家，在方案比对中查看遗漏、冲突和原文依据。
4. 生成反馈，进入商家工作区修订，提交新版本后重新核对。
5. 查看空间模型、管线图层和需求关联，再选择方案并保留现场待办。
6. 在需求维度量表填写19项信息、重要程度和确认依据，测试刷新恢复。
7. 变更已发布需求，确认旧方案不再被显示成针对新基准的通过结果。

首页也提供完整案例快捷入口。真实数据未输入时，不显示虚构的AI完成率或商家排名。
