# Requirement submission insight

Mode: Operate. Extension of the existing requirements screen; no identity change.

## Direction contract

THESIS: Turn a published requirement list into an explorable map of its relationships, followed by grounded quantities and next decisions. The user selected dynamic requirement graph + quantified conclusions.

OWN-WORLD: Inherit Lucid cream white, mist purple and ice blue, Noto Serif SC headings, platform body text, quiet glass task surfaces and existing buttons. Add no new brand or assets.

STORY: A second Flash request reviews the immutable published snapshot. Users see actual request state, then inspect clarity, checks and relationships with source quotations; continue to the existing comparison flow.

FIRST VIEWPORT: Large graph at left, an editorial column of actual counts at right. Published version and request status precede it. Node selection reveals supporting text below; retry/back/continue remain explicit. Mobile stacks graph and counts without page overflow.

FORM: Code-led graph expansion, directly selected by the user; no concept roll for this scoped extension. One animated node-and-edge reveal, reduced-motion equivalent, no simulated model progress or fabricated scores.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
