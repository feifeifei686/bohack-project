# Guided continuation

Mode: Operate. User chose one floating bottom bar for every Next action. Clicking an incomplete step should locate and highlight the required field.

## Direction contract

THESIS: Give the user one steady place to continue and explain the precise missing input instead of leaving a disabled button.

OWN-WORLD: Inherit Lucid cream and mist purple, existing type and rounded controls. One glass surface separates task navigation from content; no new identity.

STORY: Read the current task, complete it, press Next. If something is missing, scroll and focus that field with two gentle emphasis pulses and a persistent text explanation. Input clears the notice. Preserve explicit adoption, publication and selection decisions.

FIRST VIEWPORT: Existing content and compact progress above; bottom bar holds task title and instruction left, Back and Next right. Mobile stacks copy over two reachable actions and reserves space below content.

FORM: Directly specified code-led workflow extension. Reuse actual business validation and existing dialogs. Busy work prevents duplicate requests; unknown optional fields remain optional. Reduced motion uses static highlighting.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
