# 雾屿 Atmosphere

以自然室内摄影、橄榄色烟玻璃和生活便签构成家装项目工作台。左侧生活叙事与主行动、右侧轻量生活提醒，下方为大幅房间模型与便签工作纸；四步流程与两家方案回应延续到可操作页面。

## 设计变量

| 用途       | 值                     |
| ---------- | ---------------------- |
| 基础背景   | #171c14                |
| 烟色面板   | rgba(34,39,29,0.62)    |
| 主要文字   | #f4f1e5                |
| 次级文字   | #c0c6b1                |
| 主要强调   | #dce5b9                |
| 分隔线     | rgba(232,236,211,0.17) |
| 待处理状态 | #e6c693                |

正文使用 Avenir Next 和中文系统字体后备，生活便签使用宋体衬线。主标题34至62px，正文14px，主要按钮至少44px。真实摄影在顶层保留物理光影，工作页进一步柔焦，界面使用24至28px backdrop-filter和细亮边缘。只在浮动层使用柔和偏移阴影，不伪造实时AI运行状态。

## 结构与交互

生活便签通过真实表单写入原始需求，并进入原有澄清流程，不覆盖已发布版本。户型沿用三维顶点SVG投影，可旋转、缩放、选房间和线路。模型采用暖白与浅橄榄色阶；所有空间数据标记为示意。

桌面使用模型工作纸与便签的非对称双栏，手机依次展示主行动、空间模型、生活便签、区域信息、方案与待办。导航是磨砂悬浮dock，完整功能入口与返回展厅始终可访问。

方案比对、19项量表、商家编辑、确认记录使用同一烟玻璃工作纸；宽表只在表格容器内滚动。原有规则、版本与数据隔离契约保持不变。背景图片来自本次内建imagegen生成的 atmosphere.webp，完整提示词在根目录public/assets/manifest.json。
